This Season: Decode

Read the pattern · Launch in order

The Challenge

Robots read a coded pattern with vision, then launch artifacts into goals in that order. Scoring rewards two things at once: reading the pattern correctly, and being able to put artifacts where you meant to, repeatedly.

That shaped the whole build. A launcher that is accurate but slow loses to one that is slightly less accurate and can cycle. Our strategy chapter is about where we chose to sit on that trade.

The Robot

Drive · Odometry · Vision · Launcher

How It Is Built

A mecanum drivetrain for free lateral movement, three-wheel odometry for position we can trust, and a dual-flywheel launcher tuned for repeatable shots rather than maximum range.

  • DrivetrainMecanum, four wheels
  • LocalisationThree-wheel odometry
  • PathingPedro Pathing
  • VisionLimelight, tuned in-house
  • ScoringDual-flywheel launcher
  • AutonomousRepeatable, pattern-driven

Code and Vision

We run Pedro Pathing for autonomous movement and a Limelight vision stack we tuned ourselves rather than taking off the shelf. The tuning process, and what we got wrong first, is written up in the portfolio.

Everything is public. The CAD, the code and these write-ups are all open source, because a season's worth of tuning notes is more useful to the next rookie team than it is sitting in our repo unread.
